# Biztonsági irányelv

Biztonsági hibát ne nyilvános issue-ban jelents. A repó tulajdonosának privát GitHub security advisory felületét használd.

A hibajelentésből távolítsd el a felhasználónevet, gépnevet, IP-címet, hozzáférési tokent, környezeti változót és felhasználói fájl tartalmát. Privát kulcsot vagy teljes naplócsomagot soha ne küldj.
